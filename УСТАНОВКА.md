# Пошаговая установка на сервер

Инструкция рассчитана на чистый сервер с Ubuntu 22.04/24.04 или Debian 12.
После каждой команды показано, что должно появиться в ответ, — так вы сразу
поймёте, если что-то пошло не так.

Всего 8 шагов, примерно 20 минут. Шаги 1–2 выполняются **на своём компьютере**,
остальные — на сервере.

Уже разворачивали похожие сервисы и нужна только шпаргалка без пояснений — короткая
версия в [DEPLOY.md](DEPLOY.md).

---

## Шаг 1. Получить токен бота

На своём компьютере, в Telegram:

1. Откройте [@BotFather](https://t.me/BotFather)
2. Отправьте `/newbot`
3. Придумайте имя (например `Топливо Кубань`)
4. Придумайте логин, обязательно заканчивающийся на `bot` — например `kuban_fuel_bot`

В ответ придёт строка вида:

```
123456789:AAHdqTcvCH1vGWJxfSeofSAs0K5PALDsaw
```

Это токен. Сохраните его — он понадобится на шаге 5.

> Токен даёт полный контроль над ботом. Не публикуйте его и никому не пересылайте.
> Если случайно засветили — `/revoke` в @BotFather выдаст новый.

---

## Шаг 2. Предварительная проверка (необязательно)

Адрес API искать вручную больше не требуется: после установки бот найдёт его сам.
Если хотите заранее проверить парсер на своём компьютере:

```bash
cd gpn_fuel_bot
pip install -r requirements.txt
playwright install chromium
python cli.py --available
```

Ожидаемый вывод:

```
Открываю https://gpnbonus.ru/fuel/refuel-map …
  ✓   412 АЗС  ←  https://gpnbonus.ru/api/...
Обнаружен API: https://gpnbonus.ru/api/...  (412 АЗС)
```

Проверьте, что парсер работает:

```bash
python cli.py --available
```

Должен появиться список АЗС с ценами и статусами.

**Если ничего не нашлось:**
- `python discover.py --show` — откроет видимое окно браузера, подвигайте карту руками
- `python discover.py --dump` — сохранит сырые ответы в `sample_*.json` для разбора
- Крайний вариант: откройте карту в браузере → F12 → вкладка Network → фильтр Fetch/XHR →
  найдите запрос со списком АЗС → скопируйте его адрес и на шаге 5 добавьте в `.env`
  строку `GPN_API_URL=<адрес>`

Никаких дополнительных файлов после проверки переносить не нужно.

---

## Шаг 3. Подключиться к серверу

Подойдёт любой VPS за 150–300 ₽/мес: боту нужно 256 МБ памяти и никаких открытых портов.

```bash
ssh root@ВАШ_IP
```

Если подключаетесь не под root, дальше добавляйте `sudo` к командам установки.

Проверьте версию Python:

```bash
python3 --version
```

Нужен **3.11 или новее**. Если версия старше или команда не найдена:

```bash
apt update && apt install -y python3 python3-venv python3-pip
```

---

## Шаг 4. Скопировать проект на сервер

Выполняется **на своём компьютере**, в папке, где лежит `gpn_fuel_bot`:

```bash
scp -r gpn_fuel_bot/ root@ВАШ_IP:/tmp/
```

Убедитесь, что основные файлы попали в копию:

```bash
ssh root@ВАШ_IP "ls /tmp/gpn_fuel_bot/bot.py"
```

Должен вывести путь к `bot.py`.

---

## Шаг 5. Вписать токен

На сервере:

```bash
cd /tmp/gpn_fuel_bot
cp .env.example .env
nano .env
```

Замените строку с токеном на свою:

```
BOT_TOKEN=123456789:AAHdqTcvCH1vGWJxfSeofSAs0K5PALDsaw
```

Сохранение в nano: `Ctrl+O`, `Enter`, затем `Ctrl+X`.

Остальные настройки можно не трогать. **Не уменьшайте `POLL_INTERVAL` ниже 120** —
это чужой публичный сервис, частые запросы приведут к блокировке вашего IP.

---

## Шаг 6. Запустить установку

```bash
sudo bash /tmp/gpn_fuel_bot/deploy/install.sh
```

Скрипт сам создаст системного пользователя, развернёт окружение, поставит зависимости
и запустит сервис. Ожидаемый финал:

```
==> Готово. Бот работает.
    Логи:      journalctl -u gpn-bot -f
    Остановка: systemctl stop gpn-bot
```

Скрипт намеренно откажется работать, если токен пустой или остался заглушкой из
примера, — чтобы сервис не «поднялся» в нерабочем состоянии.

---

## Шаг 7. Проверить, что всё живо

```bash
systemctl status gpn-bot
```

В строке должно быть `active (running)`. Затем посмотрите логи:

```bash
journalctl -u gpn-bot -n 30 --no-pager
```

Ожидаемые строки:

```
Обновлено АЗС: 412, изменений: 0
Бот запущен, интервал опроса 300 с
```

`изменений: 0` в первый раз — это нормально: первый прогон только запоминает текущее
состояние, уведомления пойдут при следующих изменениях.

Теперь откройте своего бота в Telegram и нажмите **Start**. Должно появиться меню:

```
[🔍 Найти АЗС]   [📍 Рядом со мной]
[⛽️ Моя АЗС]     [🔎 Где есть топливо]
[🔔 Подписки]    [❓ Помощь]
```

Нажмите «🔍 Найти АЗС» → выберите город → выберите АЗС → нажмите на нужную марку,
чтобы значок сменился на 🔔. Готово, слежение включено.

---

## Шаг 8. Настроить резервную копию

Все подписки и история лежат в одном файле. Настройте ежедневный бэкап:

```bash
mkdir -p /root/backups
crontab -e
```

Добавьте строку:

```
0 4 * * * sqlite3 /var/lib/gpn/gpn.db ".backup '/root/backups/gpn-$(date +\%F).db'"
```

---

## Что делать дальше

**Обновить код после правок:**

```bash
scp -r gpn_fuel_bot/ root@ВАШ_IP:/tmp/
ssh root@ВАШ_IP "sudo bash /tmp/gpn_fuel_bot/deploy/install.sh"
```

Скрипт можно запускать сколько угодно раз, база при этом не трогается.

**Полезные команды:**

| Команда | Что делает |
|---|---|
| `journalctl -u gpn-bot -f` | смотреть логи в реальном времени |
| `systemctl restart gpn-bot` | перезапустить |
| `systemctl stop gpn-bot` | остановить |
| `systemctl disable gpn-bot` | убрать из автозапуска |

## Если что-то не работает

**Сервис не стартует.** `journalctl -u gpn-bot -n 50` — в 9 случаях из 10 это пустой или
неверный `BOT_TOKEN` в `/opt/gpn_fuel_bot/.env`.

**В логах «Не удалось получить данные АЗС».** Автоматический поиск не смог открыть
карту либо сайт ограничил IP сервера. Выполните
`cd /opt/gpn_fuel_bot && .venv/bin/python discover.py --verbose`; при необходимости
задайте найденный URL переменной `GPN_API_URL` в `.env`.

**Бот отвечает, но список АЗС пуст.** Сайт мог изменить схему ответа. Проверьте
`cd /opt/gpn_fuel_bot && .venv/bin/python cli.py --all-regions` — если данные приходят,
но пусты по краю, дело в фильтре региона; если не приходят вовсе — повторите шаг 2.

**Уведомления не приходят.** Убедитесь, что у марки стоит 🔔, а не 🔕, и что с момента
включения статус действительно менялся. Уведомление уходит только на переход
«отсутствует → в наличии», а не на каждый опрос.

**Бот перестал отвечать через несколько дней.** Проверьте, не заблокировал ли сайт IP
сервера: `journalctl -u gpn-bot | grep -i "ошибка опроса"`. Если да — увеличьте
`POLL_INTERVAL` в `/opt/gpn_fuel_bot/.env` и перезапустите сервис.
